## Problem

Students arrived with uneven C# fluency. The course needed one path that still felt like real production constraints.

## Approach

Template repo carried analyzers, scene bootstraps, and a single blessed input stack. Lecture repos only diverged where pedagogy required it.

## Outcome

Learners spent more time on game feel and less on mystery compiler errors. Teaching assistants used the same diagnostics, so office hours stayed short and specific.
